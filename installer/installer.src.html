Connect your radio

Everything happens in this browser, over USB. Nothing is uploaded anywhere.

  • Switch the radio on and plug it into this computer with a USB data cable (some cables only charge).
  • Use Chrome, Edge or Opera on a computer. Close the NOVA Editor and any other program that uses the radio.
  • When asked, pick the port named USB JTAG/serial debug unit or ESP32-S3.
This browser cannot talk to USB devices. Open this page in Chrome, Edge or Opera on a Windows, macOS, Linux or ChromeOS computer.
Force the radio into install mode: switch it off, hold the BOOT button (on the board, or the knob on some models), plug the cable in or switch it on, then release BOOT and click Connect again. The screen stays dark in this mode; that is normal.

Back up the current firmware

Recommended the first time: a complete copy of the radio's memory, so you can always go back to the original firmware.

  • Takes about two minutes. The file (8 MB) is saved to your Downloads folder.
  • To go back later: Advanced options below, "Restore a backup".

Install NOVA __VERSION__

Keep the cable plugged in until the end. It takes about a minute, then you switch the radio off and on.

NOVA is installed

Everything was written and checked.

Now switch the radio off and on againAfter an install over USB the radio does not always restart by itself and can stay on a dark screen. This is normal: switch it off, then on, and it starts with the NOVA star. If the screen stays dark, unplug the USB cable and switch it on again.
  • Find stations: on the radio, hold the knob, then Search stations. Or let the editor do it.
  • Station names, clock and every setting: open the NOVA Editor in Chrome or Edge and click Connect radio.
  • Learn the controls: turn to move, click to choose, hold for the menu.
