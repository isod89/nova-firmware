**NOVA 2.0.0, the first public release.**

Install from your browser with **NOVA-Installer.html** (Chrome, Edge or Opera, works offline), or download the full package below.

- New logo and animated boot screen, 19 themes
- One-page installer with backup, update and restore
- Ghost Box with profiles, clusters, RF trigger, catch, answer window, blind mode and a full review studio in the editor
- Noise Hunter, Storm Detector, six visualizers
- EiBi station names over Wi-Fi or USB

See the [changelog](https://github.com/isod89/nova-firmware/blob/main/CHANGELOG.md) for everything.
Make a backup first, the installer makes it easy. Please report how NOVA runs on your radio.
