# Changelog

## 2.0.0 - first public release

**Installer update (after release)**
- The installer, the editor and the docs now tell you to switch the radio off and on after a USB install:
  the radio does not always restart by itself and can stay on a dark screen.
- The website and the release files are refreshed from `main` without a new firmware version.

**New**
- New NOVA identity: logo, and an animated boot screen that plays while the radio starts (Settings > Display > Boot animation).
- 19 themes: Dark, Light, Material, Night red, Amber, NOVA (new default), Ocean, Forest, Sunset, Graphite, Nord,
  Dracula, Solarized, Matrix, Retro LCD, Paper, Arctic, Rose, High contrast.
- NOVA Installer: a one-page web installer with automatic build detection, backup, clean install, update and restore.
- Command line installers for Windows, macOS and Linux.
- Documentation, simulator and automated builds for the public repository.

**Improved**
- Clearer gesture hints in the apps; Storm Detector status line no longer overlaps.
- Settings migrate from every earlier NOVA version.

**Removed**
- The audio path test of 1.9.1 (it answered its question: the ATS Mini has no processor audio path).

## 1.9.x
- Ghost Box **Catch**: stays on a frequency with a real signal long enough to hear a word. Adjustable hold after a mark.
- EiBi schedule and clock over Wi-Fi, with the network saved from the editor. Wi-Fi is off the rest of the time.

## 1.8.0
- Ghost Box: profiles, Shuffle and Dual sweeps, clusters around stations, noise control, reaction-time correction,
  hold after a mark, answer window, RF trigger, session history on the radio.
- Editor: spectrogram, zoom and boost in the review, source check, session files, saved notes, printable report,
  sessions saved on the radio.

## 1.7.0
- Classic, light visualizers. Ghost Box content modes, chaos, custom range, session timer, blind mode, question marks.
- Editor: recording synchronised with the Ghost Box log, review, WAV and clip export, live echo.

## 1.6.0

## 1.5.0
